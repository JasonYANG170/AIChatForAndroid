# 凭据配置 / Credential configuration

首次运行时输入自己的 VVHAN_QQSC_KEY，保存在应用私有配置中；清除应用数据即可删除。不要在安装包中分发共用服务密钥。

Enter your own VVHAN_QQSC_KEY at first launch. It is kept in app-private preferences; uninstalling or clearing app data removes it. User-owned client credentials can be extracted from a compromised device. Do not distribute shared service secrets in APKs.

已公开的真实凭据仍须撤销或更换。历史重写不能清除其他人的克隆、Fork 或 GitHub 缓存。

Revoke or rotate real credentials that were exposed. Rewriting history does not remove other clones, forks, or GitHub caches.
