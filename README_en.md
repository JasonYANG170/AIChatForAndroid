## Features
- ✅ ChatGPT3.1
- ✅Single-turn conversations
- ✅ Continuous conversations
- ✅ Cloud service request


# Compatible models
Support Android7.0-Android13.0 devices.

Supports HarmonyOS 2.0–3.1 devices.

Adapt to dark mode.

Suitable for tablet and folding screen devices
